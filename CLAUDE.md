# Diretrizes do Projeto: Gerenciador de Tarefas

## Sobre o Projeto
Este é um aplicativo console em C# destinado ao gerenciamento de tarefas diárias.

## Regras de Código (Guidelines)
- **Idioma:** Todo o código fonte (variáveis, métodos, classes) e comentários devem ser escritos estritamente em Português do Brasil.
- **Padrão de nomenclatura:** Utilize `PascalCase` para Classes e Métodos. Utilize `camelCase` para variáveis locais e parâmetros.
- **Simplicidade:** Mantenha a aplicação rodando exclusivamente no Console. Não adicione bibliotecas externas complexas sem necessidade.
- **Boas Práticas:** Sempre adicione um comentário XML (`/// <summary>`) antes de métodos de regra de negócio, explicando o que o método faz.
