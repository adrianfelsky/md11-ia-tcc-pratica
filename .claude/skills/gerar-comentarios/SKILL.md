# Skill: Documentar Código C#

## Descrição
Use esta skill sempre que o usuário pedir para "documentar" ou "adicionar comentários" a um arquivo ou método.

## Instruções de Execução
1. Analise o método ou a classe fornecida.
2. Identifique quais são os parâmetros de entrada (`<param>`) e qual é o retorno esperado (`<returns>`).
3. Adicione o bloco de comentário XML padrão do C# diretamente acima da declaração, em português claro e conciso.
4. Identifique trechos de lógica muito complexa no corpo do método e adicione um comentário curto de uma linha (`//`) explicando aquele trecho específico.
5. Devolva apenas o código final refatorado, sem inventar novas funcionalidades.
